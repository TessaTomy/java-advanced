# 🎨 _Pixel Art Studio_

_A fun **JavaFX micro-project** that lets you create pixel art with customizable grid sizes, colors, and tools.  
Built as a learning project to explore JavaFX, FXML, and interactive UI design._


## ✨ Features
- 🖌️ Paint pixels with any color using a color picker
- 🧽 Eraser tool to remove mistakes
- 🔄 Clear canvas with one click or shortcut `[C]`
- 🎛️ Adjustable grid size (16×16 up to 64×64)
- 🎨 Styled UI with gradients, shadows, and custom fonts
- ⌨️ Keyboard shortcuts:  
  - `C` → Clear canvas  
  - `E` → Toggle eraser
